## TLS: N threads bump a _Thread_local / [ThreadStatic] counter; main checks each thread's result,
## that the addresses are distinct and that main's own copy is unchanged
native win/linux, with a barrier (all threads alive when addresses are compared):
                                  0 of 20 (win -O0, -O2, 4x1e6 and 8x1e5) and 0 of 20 (linux) failed
native win, without the barrier:  first run at -O0 (4x1e6) failed 'addresses distinct 0';
                                  then 1 of 20 (-O2, 4x1e6) and 0 of 20 (-O0) failed: the runtime reuses
                                  an exited thread's TLS block, so the check is flaky without a barrier
CLR [ThreadStatic] net48/8/10 and WSL net8/10: 4 threads, 0 wrong, main's value unchanged

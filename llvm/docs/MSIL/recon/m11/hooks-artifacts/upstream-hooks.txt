# upstream-hooks.txt - DRAFT (recon M11 items 6/7) of msil/utils/upstream-hooks.txt.
# Every upstream file the MSIL fork changes (git diff <upstream base> HEAD, minus fork-only paths)
# needs a 'hook' block. Inside a block, at least one of:
#   lit <path-or-glob>      upstream lit test(s), relative to the repository root; run in one
#                           llvm-lit invocation with the shared build's tools
#   gtest <exe> [<filter>]  upstream unit tests (exe relative to the build dir)
#   compile                 compiled by the private hooks build (hooks-compile leg)
#   utc <test>...           run-utc-tests.py tests (the 'utc' row of item 8)
#   none <reason>           no runnable upstream test; the reason is required
# and optionally 'fork <path>' lines naming the fork tests that pin the MSIL behaviour (each must
# exist). 'fork-only <path>' marks a fork file that lives in an upstream directory. 'allow <test>
# <reason>' accepts one lit FAIL (environment only); an allow entry whose test passes is stale.
# Fork-only prefixes (never hooks): llvm/lib/Target/MSIL/ llvm/test/CodeGen/MSIL/ llvm/docs/MSIL/
# llvm/unittests/Target/MSIL/ clang/test/CodeGen/MSIL/ msil/ .github/msil/

# The normalizations of the equivalence oracles O3 and O4 (plan 5.12.6), read
# by msil/utils/msil-equiv.py (%msil_equiv) and msil/utils/msil-prog.py
# (--equiv-skip), and the skip lines of O3, O4 and O6, which
# msil/utils/msil-verify.py (--md-baseline with --equiv-skip) reads for O6.
#
# O3: canon(clang -c + msil-ld --no-gc-sections) == canon(clang -S + ilasm),
#     one translation unit (%{msil_c} and %{msil_ll} under msil_pipeline=obj
#     with msil_equiv=1).
# O4: canon(msil-ld LTO image, --no-gc-sections) ==
#     canon(ilasm(msil-ld --lto-emit-asm)), several translation units
#     (%{msil_prog} under msil_pipeline=lto, msil_link_output=pe, with
#     msil_equiv=1).
# canon is canonical listing v1 (plan 5.7.10: llvm-cil-dump --canonical, or
# mdcanon); everything else in it (.maxstack, locals, EH clauses, data bytes,
# P/Invoke rows, encoding forms and every operand) must match exactly.
#
# An entry is '<name> <option>[ <option>]... # <justification>': each option
# is a dumper option of canonical listing v1 whose default ('keep') is the
# listing unchanged, and it applies while the listing is produced, before
# sorting. A comparison names the entries it allows (--allow <name>):
#   O3: assembly-hash ilasm-params ilasm-initlocals snan-quiet pinvoke-module
#       pinvoke-access, plus scopes in the reference legs (msil_references);
#   O4: assembly-hash ilasm-params ilasm-initlocals snan-quiet, plus scopes in
#       the reference legs.
# The object oracle of M19 (cli-corpus-check.py --mode object,
# llvm/test/CodeGen/MSIL/object-form-text.ll) uses the options of
# ilasm-params, ilasm-initlocals and snan-quiet directly.
#
# A 'skip <oracle>[@<triple>][:<level>] <test path> <reason>' line (oracle
# O3, O4 or O6) names a difference that no normalization removes:
# msil-equiv.py --oracle <O> --test <path> prints '<O> skipped: <reason>' and
# passes, and msil-prog.py --equiv-skip builds neither equivalence output for
# the test (O3, O4); msil-verify.py --md-baseline with --equiv-skip and the
# test's --test, --triple and --level prints 'O6 skipped: <reason>' instead of
# comparing the PEVerify /md messages of the image that runs with those of
# the -S build (O6; plan section 12, 'M21.c extended'). Each line covers its
# own oracle only: an O3 line never skips O6, nor an O6 line O3.
# The path is repository-relative; one that ends in '/' covers every test
# below that directory. A line that names an MSIL triple ('@<triple>') or a
# level (':<level>', one of O0, O1, O2, O3, Os and Oz) covers the test only
# for that triple or level (the composites pass the test's --triple and
# --level to both scripts); a line that names neither covers every triple
# and level (plan section 12, 'Plan 5.12.6 amended (skip lines)'). A skipped
# test stays in every other check. msil/test/README.md lists every line of
# this file.

assembly-hash --assembly-hash=ignore # msil-ld writes the Assembly row's HashAlgId as SHA1 (0x8004, plan 5.9.12, as Roslyn does); ilasm writes 0 without a '.hash algorithm' directive, which -S and --lto-emit-asm text never print (metadata-writer 2)
ilasm-params --params=drop # ilasm adds one Param row per parameter (A_<n> when unnamed, the text's name otherwise, 'args' on the entry point, A_0 on P/Invoke stubs); codegen and msil-ld write none, and the rows it drops have Flags 0 and no FieldMarshal or Constant row
ilasm-initlocals --initlocals=ignore-without-locals # both ilasms keep an explicit .maxstack below 8 on a small body without .locals and EH clauses by writing a fat header with InitLocals set (plan section 12, M16 row of 2026-10-23); codegen and msil-ld never set InitLocals (D13), and bodies with a local signature are compared as they are
snan-quiet --snan=quiet # both ilasms quiet float32 signaling-NaN constants (ldc.r4), while the MC encoder and msil-ld keep their bits; float64 operands, Constant blobs and data bytes are compared as they are (metadata-writer 3.4, mc-streamer E4)
pinvoke-module --pinvoke-module=strip # -S binds P/Invokes through the frozen D14 table, msil-ld through native libraries with Q13 module strings (plan 5.10.11, 5.10.13), so the ImplMap scopes and ModuleRef rows differ; entry names, ImplMap flags and signatures are compared as they are
pinvoke-access --pinvoke-access=ignore # -S prints D14 P/Invokes public, msil-ld writes its P/Invoke stubs assembly (plan 5.10.11); only MemberAccess of methods with PinvokeImpl is cleared
scopes --scopes=strip # -S and --lto-emit-asm text print [mscorlib], while msil-ld's reference legs bind the BCL to the reference packs (plan 5.11.8); allowed only when msil_references is not none

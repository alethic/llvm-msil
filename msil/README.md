# msil/: the MSIL project

Everything of the MSIL backend fork that is not part of LLVM or clang proper: the execution
test suite, its harness and verification tools, the CI and gate scripts, the manifest and fetch
script of the Phase 2 exit corpus (whose third-party sources are downloaded into a cache outside
the repository, never committed), and the build helpers of the development host. Like LLVM, the
project ships compiler tools only, and since M25 the build of the helper archive
`clang_rt.builtins` (`lib/builtins/`, `utils/build/build-builtins.py`): compiler-rt's builtins
compiled for each MSIL triple, which clang links statically into each program or library that
calls one of them, as a native link takes them from compiler-rt; since P-1a also for the
portable triple `msil64-unknown-dotnet`, whose assemblies name no CPU, operating system or native
library. Since P-1b it also builds that triple's C library (`lib/libc/`,
`utils/build/build-libc.py`): the fork's LLVM libc (`libc/`), built by llvm-libc's own CMake and
linked into the shared library assembly `c.dll`, a C library that programs link and deploy
beside themselves like any library assembly of their own. Nothing
here is a runtime library that compiled programs need at run time (generated assemblies depend
only on the .NET base class library, the native libraries they P/Invoke, which a portable
assembly never does, and, since M22, the library assemblies of your own that they link). It is built as an LLVM *external project*, so no upstream CMake file
changes:

```sh
# CI and other hosts: the cache file sets projects, targets and the external project.
cmake -G Ninja -S llvm -B build -C msil/cmake/caches/MSIL.cmake
# or, explicitly:
cmake -G Ninja -S llvm -B build -DLLVM_EXTERNAL_PROJECTS=msil -DLLVM_EXTERNAL_MSIL_SOURCE_DIR=<repo>/msil ...
```

On the Windows development host use `msil/utils/build/msil-configure.ps1`, which passes the
same two variables (see [utils/build/README.md](utils/build/README.md)). The MSIL target itself
is experimental: it goes in `LLVM_EXPERIMENTAL_TARGETS_TO_BUILD`, never in
`LLVM_TARGETS_TO_BUILD`. `MSIL.cmake` enables it once `llvm/lib/Target/MSIL` exists.

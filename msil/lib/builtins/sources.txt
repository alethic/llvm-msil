# The sources of the MSIL helper archives clang_rt.builtins (plan 5.14.3), read
# by msil/utils/build/build-builtins.py, which compiles them into CIL objects
# and archives them for each MSIL triple.
#
# Format: one line per source,
#   <repository-relative path>[ <triple glob>[,<triple glob>...]]
# where no glob means every MSIL triple; '#' starts a comment. The order of the
# lines is the order of the archive members. Every .c file of GENERIC_SOURCES
# and BF16_SOURCES in compiler-rt/lib/builtins/CMakeLists.txt is either listed
# or named by a line
#   # excluded <path>: <category>: <reason>
# whose <category> is one of
#   int128  passes __int128 (compiler-rt's *ti* functions)
#   fp128   binary128 tf_float, which MSIL does not have
#   x87     x87 80-bit long double (MSIL's long double is double)
#   hosted  needs a C library header or an operating system service
#   atomic  atomics, which follow user decisions R4/R5 (plan 5.14.2 N-3)
# and 'build-builtins.py --check-list' checks that after every upstream merge.
# The native compiler-rt oracle of the Linux harness ('build-builtins.py
# --native-oracle', E7h) adds the int128, fp128 and x87 sources back, with
# compiler-rt's TF, x87 and x86_64 lists, and never a hosted or atomic one.
#
# compiler-rt's other lists are not families of these archives:
# GENERIC_TF_SOURCES (fp128; on aarch64 they would compile with a double
# tf_float and be wrong), x86_80_BIT_SOURCES (x87), x86_ARCH_SOURCES and the
# architecture directories (inline assembly, .S files, variants of the generic
# sources). Every listed source compiles with build-builtins.py's command for
# each triple it is listed for (plan 5.14.3 A2), and members are hidden
# (-fvisibility=hidden), so an output never exports one (A7).
#
# int_util.c includes <stdlib.h> on _WIN32 targets, which a freestanding
# compile does not have, so it is listed for the Linux triples and the portable
# triples (*-unknown-dotnet) only, and so are the -ftrapv helpers that call its
# __compilerrt_abort_impl through compilerrt_abort() (absv*, addv*, mulv*,
# negv*, subv*): on a Windows triple their link would name that missing
# function rather than the helper. Without _WIN32 and with -ffreestanding,
# __compilerrt_abort_impl is a weak, hidden __builtin_trap().
#
# The portable triple msil64-unknown-dotnet (plan 5.18.8) has its archive only
# when 'build-builtins.py --triple msil64-unknown-dotnet' names it. It takes
# every line without a glob, the *-unknown-dotnet lines, and no host family:
# msil_longdouble.c (long double is double there), the windows-msvc stdio
# files, atomic.c and the *ti* sources stay out. It defines no __ELF__, so
# comparedf2.c and comparesf2.c (compiler-rt/lib/builtins/int_lib.h's alias
# branch, which also takes __dotnet__) define no __cmpdf2 and __cmpsf2
# aliases there; the backend lowers floating-point compares inline, so no MSIL
# code calls them.

# The link-semantics matrix (ImplementationPlan.md 5.9.16, 5.12.7,
# condition 5, and 5.17.12): one line per row of 5.9.16 and per variant of a
# row, and the other tests of this directory. Inputs/check-matrix.py (run by
# matrix-coverage.test, and with --legs by the phase gates) checks each line
# against its tests and the legs; its docstring has the rules.
#
# Columns, separated by '|':
#   case        the 5.9.16 row, or <row>/<variant>
#   tests       relative to msil/test/M2, or to the repository (llvm/...)
#   native      transcript | link error | UB | n/a, then ': <what>', then any
#               clauses '; rule <triple>: <why>' (on that triple the test's
#               expected file is hand-written, %{msil_expected_rule})
#   pipelines   asm, obj, lto (obj and lto: %{msil_prog} in the legs whose
#               msil-prog-pipeline is obj or lto)
#   triples     linux-gnu (x86_64-unknown-linux-gnu-msil, WSL .NET 10 and the
#               private .NET 8), windows-msvc (x86_64-pc-windows-msvc-msil,
#               .NET 8, .NET 10 and Framework 4.8)
#   Phase 2     transcript (the native one, at -O0 and -O2 and every level of
#               the leg) | diag:<text> (a named diagnostic, exit status 1,
#               checked at -O0 and at -O2; '<...>' is a part the test matches
#               as a pattern) | untested: <reason> | object: <what>
#   milestones  5.9.16's 'From' column. 'P3', 'P3-A' or 'P3-B' marks a P3
#               row, whose test pins today's diagnostic: the milestone that
#               builds its feature writes its own id in place of the label and
#               makes the line a transcript. A line that names a milestone
#               from M24 to M35 runs in the gate legs with 10+tc0 (the
#               checker's gate rule) and joins their $p3Tests
#               (check-matrix.py --p3-tests).
#
# Header lines ('#!' lines are not comments to the checker; each repeatable):
#   #! rows:      the rows that need a line: 5.9.16's and those Phase 3 adds
#   #! obj-lto:   the rows whose lines list obj and lto (over their variants)
#   #! p3-tests:  Phase 3 feature tests outside msil/test/M3 that no line
#                 names (repository-relative paths), for the gate legs
#
# case | tests | native | pipelines | triples | Phase 2 | milestones
